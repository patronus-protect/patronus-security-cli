# Privacy

Repository traversal, document extraction, decoding, chunking and report generation occur locally. In Local mode, Ark analysis also stays on the device. API mode sends scan text to `https://control.patronus.studio/api/v1/scan`; Hybrid keeps user prompts and results/files of at most 2048 tokens local but sends every chunk of larger tool/MCP results or files to that API. Repository scans decide independently per file. Explicit public URL and MCP-server audits use the API in every processing mode. A complete file is uploaded anonymously only with `scan file PATH --anonymous-api`; ordinary file scans send extracted text chunks according to the configured processing mode. The signed pseudonymous quota cookie is stored privately under the scanner's user data root and is sent only to the configured fixed Control Plane origin. Envelope metadata and media bytes are not submitted as runtime scanner input.

The scanner has no telemetry, analytics, crash upload or background service. Ark model preparation may access the network only when `assets prepare` or `ark.download_files = true` is explicitly selected.

`support-us` is the only support submission surface. It creates a local ZIP, removes absolute scan roots and evidence arrays from default members, prints every member, and requires confirmation. Source files are never included unless named exactly with `--include`; `--dry-run` always performs no request. The optional token is read only from `PATRONUS_SUPPORT_TOKEN` and is never persisted or printed.
