Updates & uninstall

Use the package manager that installed the CLI. Plugin releases are managed separately.

CLI

patronus-security-scanner maintenance update
patronus-security-scanner maintenance uninstall --yes

Cargo and standalone installations in ~/.local/bin can update through this button. Public releases must be published first. Reports and settings are preserved.

Plugins

Claude and Codex update from their registered marketplace (currently patronus-local). DeepSeek uses its verified public release archive. Each integration above can be disabled or uninstalled independently.

patronus-security-scanner integration codex uninstall
patronus-security-scanner integration claude uninstall
patronus-security-scanner integration deepseek uninstall
